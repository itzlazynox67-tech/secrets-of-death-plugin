# Collectible items and model mapping

The plugin gives collectible items using `/secrets give <player> <id>`. All collectibles carry a persistent `collectible_id` value. All model identifiers are independent so individual textures can be replaced separately.

| Command ID | Model ID |
|---|---|
| `book` | `modeling:death_of_destruction` |
| `deaths_embrace` | `modeling:death_embrace` |
| `eclipse` | `modeling:eclipse` |
| `deadlock` | `modeling:deadlock` |
| `blastforge` | `modeling:blastforge` |
| `hellfire` | `modeling:hellfire` |
| `phoenix_wings` | `modeling:phoenix_wings` |
| `explosion_gift` | `modeling:explosion_gift` |
| `death_helmet` | `modeling:death_overlayer_helmet` |
| `death_chestplate` | `modeling:death_overlayer_chestplate` |
| `death_leggings` | `modeling:death_overlayer_leggings` |
| `death_boots` | `modeling:death_overlayer_boots` |

The resource pack includes the original supplied art and independent placeholder textures for entries that did not have individual supplied art. These are display/collectible items in this starter, not active combat equipment.
